NORTHLINE LOW VOLTAGE WEBSITE

Open this folder in Visual Studio Code:
1. Extract the ZIP file.
2. In VS Code, choose File > Open Folder.
3. Select the northline-low-voltage-site folder.
4. Open index.html in your browser, or use the Live Server extension.

Files:
- index.html   Website structure and content
- styles.css   Styling and responsive layout
- script.js    Mobile navigation and quote-form email draft

Before publishing:
- Replace the temporary business name, phone, email, and service area.
- Update YOUR_EMAIL@example.com in script.js to your actual business email.
- Confirm image usage rights or replace sample images with your own job photos.
- The quote form currently opens the visitor's email app; it does not submit to a server.
